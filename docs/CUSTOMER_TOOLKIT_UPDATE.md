# Customer toolkit refresh
New budget, hire and snag tools are device-local, scoped by signed-in account and mode. They do not modify bookings, quotes, payments, or verification. Plans require explicit Save and can be shared as text. No server migration or cross-device sync in this release. Existing tools retained. Research: https://www.citizensadvice.org.uk/consumer/getting-home-improvements-done/before-you-get-building-work-done/ and https://hoa.org.uk/advice/guides-for-homeowners/i-am-improving/home-repairs-and-improvements/ .

The planning screens guard normal in-app tab navigation and back navigation when changes are unsaved. Reset plan removes the stored plan for the current account and tool.
